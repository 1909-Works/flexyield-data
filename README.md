# FlexYield public-pool reliability data

Weekly, measured, machine-readable: uptime, p50/p95 latency and error rates of public and premium-class RPC supply across six mainnets, as observed by the FlexYield gateway's continuous probes (every 5 minutes per endpoint) and relays. Same data as https://flexyield.io/reliability — this repository is the archive you can clone, chart and cite.
